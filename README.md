# Empleos Tech en El Salvador

Listado actualizado de oportunidades tecnológicas abiertas para personas en El Salvador.

Las plazas se organizan por categoría y por fecha de publicación, de la más reciente a la más antigua. Cada entrada indica modalidad, ubicación, salario cuando la empresa lo publica, fuente y enlace directo.

> La primera actualización automática se está preparando.

## Categorías

- Desarrollo de software
- QA y testing
- Datos e inteligencia artificial
- DevOps, cloud y ciberseguridad
- Soporte, redes e infraestructura
- Producto, UX/UI y gestión tecnológica

## Criterios

- Solo se incluyen ofertas cuya página sigue activa.
- Se excluyen plazas vencidas, cerradas o sin vigencia verificable.
- No se inventan salarios ni modalidades: cuando no se publican, se indica claramente.
- Se eliminan duplicados entre distintas bolsas de empleo.
